# ML-Systematic-Trading-Engine

This project is an independent reimplementation and extension of concepts presented in the memlabs “[Let’s Build a Quant Trading Strategy](https://youtube.com/playlist?list=PLdsqLas3-Kg3fM8VgykXBJ2gRIFBpKHjY&si=hHZwOfD49Qy-AGZe)” series. The architecture, model design, and execution framework have been restructured and extended for modularity and experimentation.
