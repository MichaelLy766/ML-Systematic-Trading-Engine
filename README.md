# ML-Systematic-Trading-Engine

This project is an independent reimplementation of the concepts presented in the memlabs “[Let’s Build a Quant Trading Strategy](https://youtube.com/playlist?list=PLdsqLas3-Kg3fM8VgykXBJ2gRIFBpKHjY&si=hHZwOfD49Qy-AGZe)” series. Extensions and modifications from the original source code provided in the videos will be added as the project goes on.
